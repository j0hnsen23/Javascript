# Passordgenerator

En enkel passordgenerator laget i JavaScript som lager tilfeldige og sikre passord.

## Funksjoner
- Velg lengde på passordet
- [Inkluder store/små bokstaver, tall og spesialtegn – fjern det som ikke stemmer]
- Kopier passordet med ett klikk [fjern hvis den ikke har dette]

## Teknologier
- JavaScript
- HTML
- CSS

## Slik kjører du den
1. Last ned eller klon repoet
2. Åpne `index.html` i nettleseren
